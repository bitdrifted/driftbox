# driftbox

> inspect the system. reduce uncertainty. trust less.

**Driftbox** is a cross-platform terminal toolkit for system inspection, security checks, and resilient operations.

Built for Linux, Windows, macOS, and Windows Subsystem for Linux (WSL).

## status

`early development`

The architecture and first command set are currently being designed.

## planned capabilities

- System and environment inspection
- Network visibility and diagnostics
- File-integrity verification
- Security configuration checks
- Portable system reports
- Cross-platform terminal interface

## compatibility

| Environment | Support |
|---|---|
| Linux terminal | Planned |
| Windows Terminal / PowerShell | Planned |
| Windows Terminal / WSL | Planned |
| macOS Terminal | Planned |

Driftbox will automatically detect the operating environment and expose only the tools supported by that system.
